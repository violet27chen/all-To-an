    支持哪些协议？
    提取原始链接
    从纯文本或 Base64 订阅中逐条提取，保留原协议和参数。支持 vless://、vmess://、trojan://、ss://（Shadowsocks）、ssr://、hysteria://、hysteria2://（含 hy2://）、tuic://、anytls://、socks://、socks5:// 和 wireguard://。
    从 Clash 配置生成链接
    读取 YAML 或 JSON 的 proxies，支持常见的 VLESS、VMess、Trojan、Shadowsocks、Hysteria2 和 TUIC 配置。无法转换的条目会跳过，结果区会显示数量。
